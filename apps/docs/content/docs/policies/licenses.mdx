## AGPL-3.0 Only

Docverse is licensed exclusively under the [GNU Affero General Public License version 3](https://www.gnu.org/licenses/agpl-3.0.html) (AGPL-3.0). There is no commercial licence, no enterprise edition and no licence key: every feature in the codebase is available to everyone under the same terms.

Docverse is a fork of [Documenso](https://github.com/documenso/documenso). The Docverse source code is available at [github.com/engenhariainversa/documenso](https://github.com/engenhariainversa/documenso), and the full licence text is in the [LICENSE file](https://github.com/engenhariainversa/documenso/blob/main/LICENSE).

## What AGPL-3.0 Allows

- Use Docverse for any purpose, including commercial use
- Access, study, and modify the source code
- Distribute copies of the original or modified software
- Self-host Docverse on your own infrastructure

## What It Means If You Host Docverse

The AGPL-3.0 includes a **network clause**: letting users interact with the software over a network counts as distributing it. If you run a Docverse instance that other people use, you must:

- **Offer the source code to your users**: the complete, corresponding source of the version you run, including any modifications you have made, under AGPL-3.0.
- **Keep notices intact**: preserve copyright notices and include a copy of the AGPL-3.0 licence.
- **Keep the same licence**: derivative works must also be licensed under AGPL-3.0.

<Callout type="info">
  The application shows a **"Código-fonte"** (source code) link so that every user can reach the
  source. If you modify Docverse, make sure that link points to the source of your modified version.
</Callout>

Signed documents and other content you create with Docverse are not covered by the licence; the AGPL-3.0 applies to the software only. Calling the API from your own application does not make that application a derivative work.
